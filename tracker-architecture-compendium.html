MOD 01 BitTorrent Tracker Internals, Bencode AST & Binary Wire Specifications
▶

A BitTorrent tracker is a stateless or semi-stateful rendezvous directory that maps an info_hash (20-byte SHA-1 in BEP 03, or 32-byte SHA-256 truncated/hybrid in BEP 52) to an active set of peer socket endpoints. Trackers never touch payload blocks; they coordinate swarm topology and collect telemetry via HTTP/HTTPS (BEP 03/23), UDP (BEP 15), or WebSockets (WebTorrent).

1.1 Deterministic Bencode Grammar (BEP 03)

Bencode is a prefix-delimited, big-endian data serialization format supporting four primitives. Unlike JSON, Bencode requires strict lexicographical sorting of dictionary keys by raw byte value so that the SHA-1/SHA-256 digest of the info dictionary is deterministic across all implementations.

Primitive Wire Grammar Byte Example Parser Invariant & Security Constraint
Integer i<base10>e i-42e, i0e 64-bit signed integer. Leading zeros (i03e) and negative zero (i-0e) are strictly malformed and must be rejected.
Byte String <length>:<bytes> 4:spam Length is ASCII base-10 followed by 0x3A (:). Raw bytes follow—not necessarily UTF-8 (e.g., peers compact array).
List l<items>e l4:spami42ee Heterogeneous sequence terminated by 0x65 (e). Enforce max recursion depth (≤ 32) to prevent stack exhaustion.
Dictionary d<key><val>e d3:bari1e3:fooi2ee Keys must be Byte Strings sorted in ascending raw byte order. Duplicate keys must trigger immediate parser abort.

1.2 BEP 23 (IPv4) & BEP 07 (IPv6) Compact Peer Lists

Returning Bencoded dictionaries per peer (d7:peer id20:...2:ip...4:port...e) wastes ~60% bandwidth. Modern trackers enforce compact=1:

  • IPv4 Compact (peers key): Contiguous byte string of 6 * N bytes. Every 6-byte stride packs a 32-bit big-endian IPv4 address (4 bytes) followed by a 16-bit big-endian port (2 bytes).
  • IPv6 Compact (peers6 key): Contiguous byte string of 18 * N bytes. Every 18-byte stride packs a 128-bit big-endian IPv6 address (16 bytes) followed by a 16-bit big-endian port (2 bytes).

MOD 02 C# .NET 8 High-Performance Tracker (Span<byte>, BinaryPrimitives, UDP & HTTP)

To handle 100,000+ announces per second without triggering Gen-2 Garbage Collection pauses, our C# .NET 8 tracker eliminates string allocations on the hot path. We represent the 20-byte InfoHash as a custom readonly record struct implementing IEquatable<InfoHash> over three ulong/uint fields, and pack each IPv4 peer endpoint + state into a single 64-bit integer (ulong).

    /// <summary>
    /// Zero-heap-allocation 20-byte SHA-1 InfoHash value type.
    /// Layout: 8 + 8 + 4 = 20 bytes exact.
    /// </summary>
    [StructLayout(LayoutKind.Sequential, Pack = 1)]
    public readonly struct InfoHash : IEquatable<InfoHash>
    {
        public readonly ulong Part1;
        public readonly ulong Part2;
        public readonly uint Part3;

        public InfoHash(ReadOnlySpan<byte> bytes)
        {
            if (bytes.Length != 20)
                throw new ArgumentException("InfoHash must be exactly 20 bytes.");
            Part1 = BinaryPrimitives.ReadUInt64BigEndian(bytes.Slice(0, 8));
            Part2 = BinaryPrimitives.ReadUInt64BigEndian(bytes.Slice(8, 8));
            Part3 = BinaryPrimitives.ReadUInt32BigEndian(bytes.Slice(16, 4));
        }

        [MethodImpl(MethodImplOptions.AggressiveInlining)]
        public bool Equals(InfoHash other) =>
            Part1 == other.Part1 && Part2 == other.Part2 && Part3 == other.Part3;

        public override bool Equals(object? obj) => obj is InfoHash other && Equals(other);

        public override int GetHashCode() => HashCode.Combine(Part1, Part2, Part3);

        public override string ToString() => $"{Part1:x16}{Part2:x16}{Part3:x8}";
    }

    /// <summary>
    /// Packed Peer State:
    /// EndpointKey (ulong): [IPv4: 32 bits][Port: 16 bits]
    /// Metadata: LastSeen Unix Seconds + IsSeeder flag.
    /// </summary>
    public struct PeerState
    {
        public uint IpBigEndian;
        public ushort PortBigEndian;
        public long LastSeenUnixSec;
        public bool IsSeeder;

        [MethodImpl(MethodImplOptions.AggressiveInlining)]
        public readonly void WriteCompact(Span<byte> dest)
        {
            BinaryPrimitives.WriteUInt32BigEndian(dest.Slice(0, 4), IpBigEndian);
            BinaryPrimitives.WriteUInt16BigEndian(dest.Slice(4, 2), PortBigEndian);
        }
    }

    public sealed class SwarmBucket
    {
        // Key: (ulong)IpBigEndian << 16 | PortBigEndian
        public readonly ConcurrentDictionary<ulong, PeerState> Peers = new();
        public int SeedersCount;
        public int LeechersCount;
        public int CompletedDownloads;

        public void UpsertPeer(uint ipBe, ushort portBe, long left, int eventType)
        {
            ulong key = ((ulong)ipBe << 16) | portBe;
            long now = DateTimeOffset.UtcNow.ToUnixTimeSeconds();

            // eventType: 0=none, 1=completed, 2=started, 3=stopped
            if (eventType == 3)
            {
                if (Peers.TryRemove(key, out _))
                    RecalculateCounts();
                return;
            }

            if (eventType == 1)
                Interlocked.Increment(ref CompletedDownloads);

            Peers[key] = new PeerState
            {
                IpBigEndian = ipBe,
                PortBigEndian = portBe,
                LastSeenUnixSec = now,
                IsSeeder = (left == 0)
            };

            RecalculateCounts();
        }

        public void RecalculateCounts()
        {
            int s = 0, l = 0;
            long cutoff = DateTimeOffset.UtcNow.ToUnixTimeSeconds() - 2400; // 40 min TTL
            foreach (var kvp in Peers)
            {
                if (kvp.Value.LastSeenUnixSec < cutoff)
                {
                    Peers.TryRemove(kvp.Key, out _);
                    continue;
                }
                if (kvp.Value.IsSeeder) s++;
                else l++;
            }
            Volatile.Write(ref SeedersCount, s);
            Volatile.Write(ref LeechersCount, l);
        }

        public int SampleCompactPeers(Span<byte> buffer, int maxPeers)
        {
            int count = 0;
            foreach (var kvp in Peers)
            {
                if (count >= maxPeers || (count + 1) * 6 > buffer.Length)
                    break;
                kvp.Value.WriteCompact(buffer.Slice(count * 6, 6));
                count++;
            }
            return count;
        }
    }

    /// <summary>
    /// Zero-Allocation Span-based Bencode Parser & Writer for HTTP Tracker Responses
    /// </summary>
    public static class BencodeEngine
    {
        public static byte[] BuildCompactAnnounceResponse(
            int interval, int complete, int incomplete, ReadOnlySpan<byte> compactPeers)
        {
            using var ms = new MemoryStream(128 + compactPeers.Length);
            // Keys strictly sorted lexicographically: complete, incomplete, interval, peers
            WriteAscii(ms, $"d8:completei{complete}e10:incompletei{incomplete}e8:intervali{interval}e5:peers{compactPeers.Length}:");
            ms.Write(compactPeers);
            ms.WriteByte((byte)'e');
            return ms.ToArray();
        }

        public static byte[] BuildFailureResponse(string reason)
        {
            byte[] reasonBytes = Encoding.UTF8.GetBytes(reason);
            using var ms = new MemoryStream(32 + reasonBytes.Length);
            WriteAscii(ms, $"d14:failure reason{reasonBytes.Length}:");
            ms.Write(reasonBytes);
            ms.WriteByte((byte)'e');
            return ms.ToArray();
        }

        private static void WriteAscii(Stream s, string text)
        {
            Span<byte> buf = stackalloc byte[text.Length];
            Encoding.ASCII.GetBytes(text, buf);
            s.Write(buf);
        }
    }

    /// <summary>
    /// Dual-Stack BEP 15 UDP & BEP 03/23 HTTP Tracker Server
    /// </summary>
    public sealed class DualBitTorrentTracker
    {
        private const ulong BEP15_MAGIC = 0x41727101980UL;
        private readonly ConcurrentDictionary<InfoHash, SwarmBucket> _swarms = new();
        private readonly byte[] _hmacSecret = RandomNumberGenerator.GetBytes(32);
        private readonly int _port;

        public DualBitTorrentTracker(int port = 6969) => _port = port;

        /// <summary>
        /// Generates a stateless anti-spoofing 64-bit connection_id bound to Client IP and 60s time bucket.
        /// </summary>
        [MethodImpl(MethodImplOptions.AggressiveInlining)]
        private ulong ComputeConnectionId(IPEndPoint remoteEp, long timeWindow)
        {
            Span<byte> input = stackalloc byte[24];
            remoteEp.Address.TryWriteBytes(input.Slice(0, 16), out int written);
            BinaryPrimitives.WriteInt64BigEndian(input.Slice(16, 8), timeWindow);

            Span<byte> hash = stackalloc byte[32];
            HMACSHA256.HashData(_hmacSecret, input.Slice(0, written + 8), hash);
            return BinaryPrimitives.ReadUInt64BigEndian(hash.Slice(0, 8));
        }

        private bool ValidateConnectionId(IPEndPoint remoteEp, ulong connId)
        {
            long currentBucket = DateTimeOffset.UtcNow.ToUnixTimeSeconds() / 60;
            return connId == ComputeConnectionId(remoteEp, currentBucket)
                || connId == ComputeConnectionId(remoteEp, currentBucket - 1);
        }

        public async Task RunUdpServerAsync(CancellationToken ct)
        {
            using var udpSocket = new Socket(AddressFamily.InterNetwork, SocketType.Dgram, ProtocolType.Udp);
            udpSocket.Bind(new IPEndPoint(IPAddress.Any, _port));
            Console.WriteLine($"[UDP BEP-15] Listening on 0.0.0.0:{_port}");

            byte[] recvBuf = ArrayPool<byte>.Shared.Rent(2048);
            byte[] sendBuf = ArrayPool<byte>.Shared.Rent(2048);

            try
            {
                EndPoint remoteEp = new IPEndPoint(IPAddress.Any, 0);
                while (!ct.IsCancellationRequested)
                {
                    var res = await udpSocket.ReceiveFromAsync(recvBuf, SocketFlags.None, remoteEp, ct);
                    int len = res.ReceivedBytes;
                    if (len < 16) continue;

                    var clientEp = (IPEndPoint)res.RemoteEndPoint;
                    int respLen = ProcessUdpPacket(recvBuf.AsSpan(0, len), sendBuf.AsSpan(), clientEp);
                    if (respLen > 0)
                    {
                        await udpSocket.SendToAsync(
                            new ArraySegment<byte>(sendBuf, 0, respLen),
                            SocketFlags.None,
                            clientEp,
                            ct);
                    }
                }
            }
            finally
            {
                ArrayPool<byte>.Shared.Return(recvBuf);
                ArrayPool<byte>.Shared.Return(sendBuf);
            }
        }

        private int ProcessUdpPacket(ReadOnlySpan<byte> req, Span<byte> resp, IPEndPoint clientEp)
        {
            ulong connIdOrMagic = BinaryPrimitives.ReadUInt64BigEndian(req.Slice(0, 8));
            uint action = BinaryPrimitives.ReadUInt32BigEndian(req.Slice(8, 4));
            uint txId = BinaryPrimitives.ReadUInt32BigEndian(req.Slice(12, 4));

            // ACTION 0: CONNECT
            if (action == 0 && connIdOrMagic == BEP15_MAGIC)
            {
                long bucket = DateTimeOffset.UtcNow.ToUnixTimeSeconds() / 60;
                ulong issuedConnId = ComputeConnectionId(clientEp, bucket);

                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(0, 4), 0); // action = 0
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(4, 4), txId);
                BinaryPrimitives.WriteUInt64BigEndian(resp.Slice(8, 8), issuedConnId);
                return 16;
            }

            // Validate stateless HMAC token for Announce (1) or Scrape (2)
            if (!ValidateConnectionId(clientEp, connIdOrMagic))
            {
                return WriteUdpError(resp, txId, "Invalid or expired connection_id token.");
            }

            // ACTION 1: ANNOUNCE (98 bytes minimum)
            if (action == 1 && req.Length >= 98)
            {
                var infoHash = new InfoHash(req.Slice(16, 20));
                long left = BinaryPrimitives.ReadInt64BigEndian(req.Slice(64, 8));
                int eventType = (int)BinaryPrimitives.ReadUInt32BigEndian(req.Slice(80, 4));
                int numWant = BinaryPrimitives.ReadInt32BigEndian(req.Slice(92, 4));
                ushort peerPort = BinaryPrimitives.ReadUInt16BigEndian(req.Slice(96, 2));

                if (numWant <= 0 || numWant > 100) numWant = 50;

                Span<byte> ipBytes = stackalloc byte[4];
                clientEp.Address.MapToIPv4().TryWriteBytes(ipBytes, out _);
                uint ipBe = BinaryPrimitives.ReadUInt32BigEndian(ipBytes);

                var swarm = _swarms.GetOrAdd(infoHash, _ => new SwarmBucket());
                swarm.UpsertPeer(ipBe, peerPort, left, eventType);

                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(0, 4), 1); // action = 1
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(4, 4), txId);
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(8, 4), 1800); // interval
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(12, 4), (uint)swarm.LeechersCount);
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(16, 4), (uint)swarm.SeedersCount);

                int peersWritten = swarm.SampleCompactPeers(resp.Slice(20), numWant);
                return 20 + (peersWritten * 6);
            }

            // ACTION 2: SCRAPE (16 + 20*N bytes)
            if (action == 2 && req.Length >= 36)
            {
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(0, 4), 2);
                BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(4, 4), txId);
                int offset = 8;
                for (int pos = 16; pos + 20 <= req.Length && offset + 12 <= resp.Length; pos += 20)
                {
                    var hash = new InfoHash(req.Slice(pos, 20));
                    if (_swarms.TryGetValue(hash, out var swarm))
                    {
                        BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(offset, 4), (uint)swarm.SeedersCount);
                        BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(offset + 4, 4), (uint)swarm.CompletedDownloads);
                        BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(offset + 8, 4), (uint)swarm.LeechersCount);
                    }
                    else
                    {
                        resp.Slice(offset, 12).Clear();
                    }
                    offset += 12;
                }
                return offset;
            }

            return WriteUdpError(resp, txId, "Unsupported BEP-15 action.");
        }

        private static int WriteUdpError(Span<byte> resp, uint txId, string msg)
        {
            BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(0, 4), 3); // action = 3 (Error)
            BinaryPrimitives.WriteUInt32BigEndian(resp.Slice(4, 4), txId);
            int len = Encoding.ASCII.GetBytes(msg, resp.Slice(8));
            return 8 + len;
        }
    }

[+] URL-Encoded Raw Byte InfoHash Parsing in C# HTTP Trackers BEP 03 HTTP Spec

A frequent bug in HTTP trackers is calling Uri.UnescapeDataString() or HttpUtility.UrlDecode() into a string, which corrupts arbitrary binary bytes above 0x7F into UTF-8 replacement characters (0xFFFD). Always decode URL percent-sequences directly into a Span<byte>:

C# // RawUrlByteDecoder.cs 
public static bool TryDecodeUrlRawBytes(ReadOnlySpan<char> urlParam, Span<byte> output, out int bytesWritten)
{
    bytesWritten = 0;
    for (int i = 0; i < urlParam.Length; i++)
    {
        if (bytesWritten >= output.Length) return false;
        char c = urlParam[i];
        if (c == '%' && i + 2 < urlParam.Length)
        {
            int hi = HexVal(urlParam[i + 1]);
            int lo = HexVal(urlParam[i + 2]);
            if (hi < 0 || lo < 0) return false;
            output[bytesWritten++] = (byte)((hi << 4) | lo);
            i += 2;
        }
        else if (c == '+')
        {
            output[bytesWritten++] = (byte)' ';
        }
        else
        {
            output[bytesWritten++] = (byte)(c & 0xFF);
        }
    }
    return true;

    static int HexVal(char ch) =>
        ch >= '0' && ch <= '9' ? ch - '0' :
        ch >= 'a' && ch <= 'f' ? ch - 'a' + 10 :
        ch >= 'A' && ch <= 'F' ? ch - 'A' + 10 : -1;
}

ANNOUNCE_INTERVAL = 1800
PEER_TTL_SECONDS = 2400


def bencode_encode(val: Any) -> bytes:
    """Strict RFC/BEP-03 deterministic Bencode serializer."""
    if isinstance(val, int):
        return f"i{val}e".encode("ascii")
    elif isinstance(val, bytes):
        return f"{len(val)}:".encode("ascii") + val
    elif isinstance(val, str):
        raw = val.encode("utf-8")
        return f"{len(raw)}:".encode("ascii") + raw
    elif isinstance(val, list):
        return b"l" + b"".join(bencode_encode(item) for item in val) + b"e"
    elif isinstance(val, dict):
        # Sort keys strictly by raw byte representation
        items = sorted(
            ((k.encode("utf-8") if isinstance(k, str) else k, v) for k, v in val.items()),
            key=lambda x: x[0]
        )
        out = bytearray(b"d")
        for k_bytes, v_item in items:
            out.extend(f"{len(k_bytes)}:".encode("ascii"))
            out.extend(k_bytes)
            out.extend(bencode_encode(v_item))
        out.append(ord("e"))
        return bytes(out)
    raise TypeError(f"Unsupported Bencode type: {type(val)}")


@dataclass(slots=True)
class PeerEntry:
    compact_addr: bytes  # 6 bytes: 4B IPv4 + 2B Port
    is_seeder: bool
    last_seen: float


@dataclass
class SwarmState:
    peers: Dict[bytes, PeerEntry] = field(default_factory=dict)
    completed: int = 0
    seeders: int = 0
    leechers: int = 0

    def upsert(self, compact_addr: bytes, left: int, event: int) -> None:
        now = time.monotonic()
        # event: 0=none, 1=completed, 2=started, 3=stopped
        if event == 3:
            self.peers.pop(compact_addr, None)
            self._recount(now)
            return

        if event == 1:
            self.completed += 1

        self.peers[compact_addr] = PeerEntry(
            compact_addr=compact_addr,
            is_seeder=(left == 0),
            last_seen=now
        )
        self._recount(now)

    def _recount(self, now: float) -> None:
        cutoff = now - PEER_TTL_SECONDS
        expired = [k for k, p in self.peers.items() if p.last_seen < cutoff]
        for k in expired:
            del self.peers[k]

        s = sum(1 for p in self.peers.values() if p.is_seeder)
        self.seeders = s
        self.leechers = len(self.peers) - s

    def sample_compact(self, num_want: int) -> bytes:
        pool = list(self.peers.keys())
        if len(pool) > num_want:
            pool = random.sample(pool, num_want)
        return b"".join(pool)


class SwarmRegistry:
    def __init__(self) -> None:
        self.swarms: Dict[bytes, SwarmState] = {}
        self.hmac_secret: bytes = os.urandom(32)

    def get_or_create(self, info_hash: bytes) -> SwarmState:
        swarm = self.swarms.get(info_hash)
        if swarm is None:
            swarm = SwarmState()
            self.swarms[info_hash] = swarm
        return swarm

    def make_connection_id(self, ip_str: str, time_bucket: int | None = None) -> int:
        if time_bucket is None:
            time_bucket = int(time.time() // 60)
        msg = f"{ip_str}:{time_bucket}".encode("ascii")
        digest = hmac.new(self.hmac_secret, msg, hashlib.sha256).digest()
        return struct.unpack("!Q", digest[:8])[0]

    def verify_connection_id(self, ip_str: str, conn_id: int) -> bool:
        bucket = int(time.time() // 60)
        return (
            conn_id == self.make_connection_id(ip_str, bucket)
            or conn_id == self.make_connection_id(ip_str, bucket - 1)
        )


class Bep15UdpProtocol(asyncio.DatagramProtocol):
    def __init__(self, registry: SwarmRegistry) -> None:
        self.registry = registry
        self.transport: asyncio.DatagramTransport | None = None

    def connection_made(self, transport: asyncio.BaseTransport) -> None:
        self.transport = transport  # type: ignore

    def datagram_received(self, data: bytes, addr: Tuple[str, int]) -> None:
        if len(data) < 16 or self.transport is None:
            return

        ip_str, src_port = addr[0], addr[1]
        conn_id, action, tx_id = struct.unpack_from("!QII", data, 0)

        # Action 0: Connect
        if action == 0 and conn_id == BEP15_MAGIC:
            token = self.registry.make_connection_id(ip_str)
            resp = struct.pack("!IIQ", 0, tx_id, token)
            self.transport.sendto(resp, addr)
            return

        # Verify stateless anti-spoofing token
        if not self.registry.verify_connection_id(ip_str, conn_id):
            err = b"Invalid or expired BEP-15 connection token"
            self.transport.sendto(struct.pack("!II", 3, tx_id) + err, addr)
            return

        # Action 1: Announce (98 bytes)
        if action == 1 and len(data) >= 98:
            (
                info_hash,
                peer_id,
                downloaded,
                left,
                uploaded,
                event,
                ip_override,
                key,
                num_want,
                port
            ) = struct.unpack_from("!20s20sqqqIIIiH", data, 16)

            if num_want <= 0 or num_want > 100:
                num_want = 50

            try:
                ip_bytes = socket.inet_aton(ip_str)
            except OSError:
                return

            compact_peer = ip_bytes + struct.pack("!H", port)
            swarm = self.registry.get_or_create(info_hash)
            swarm.upsert(compact_peer, left, event)

            peers_blob = swarm.sample_compact(num_want)
            header = struct.pack(
                "!IIIII", 1, tx_id, ANNOUNCE_INTERVAL, swarm.leechers, swarm.seeders
            )
            self.transport.sendto(header + peers_blob, addr)
            return

        # Action 2: Scrape
        if action == 2 and len(data) >= 36:
            out = bytearray(struct.pack("!II", 2, tx_id))
            offset = 16
            while offset + 20 <= len(data):
                ih = data[offset:offset + 20]
                sw = self.registry.swarms.get(ih)
                if sw:
                    out.extend(struct.pack("!III", sw.seeders, sw.completed, sw.leechers))
                else:
                    out.extend(b"\x00" * 12)
                offset += 20
            self.transport.sendto(bytes(out), addr)


async def handle_http_client(
    reader: asyncio.StreamReader,
    writer: asyncio.StreamWriter,
    registry: SwarmRegistry
) -> None:
    try:
        req_line = await asyncio.wait_for(reader.readline(), timeout=5.0)
        if not req_line:
            return
        parts = req_line.decode("latin-1").split(" ")
        if len(parts) < 2:
            return

        path_and_query = parts[1]
        peername = writer.get_extra_info("peername")
        client_ip = peername[0] if peername else "127.0.0.1"

        # Consume remaining HTTP headers
        while True:
            hdr = await reader.readline()
            if not hdr or hdr == b"\r\n":
                break

        parsed = urllib.parse.urlsplit(path_and_query)
        if parsed.path != "/announce":
            payload = bencode_encode({"failure reason": "Endpoint not found"})
        else:
            # Parse raw bytes from query string (critical for binary info_hash)
            qs = urllib.parse.parse_qs(parsed.query, keep_blank_values=True, encoding="latin-1")
            ih_raw = qs.get("info_hash", [""])[0].encode("latin-1")
            port = int(qs.get("port", ["6881"])[0])
            left = int(qs.get("left", ["1"])[0])
            ev_str = qs.get("event", [""])[0]
            ev_map = {"": 0, "completed": 1, "started": 2, "stopped": 3}
            event = ev_map.get(ev_str, 0)

            if len(ih_raw) != 20:
                payload = bencode_encode({"failure reason": "Invalid 20-byte info_hash"})
            else:
                compact_peer = socket.inet_aton(client_ip) + struct.pack("!H", port)
                swarm = registry.get_or_create(ih_raw)
                swarm.upsert(compact_peer, left, event)
                payload = bencode_encode({
                    "interval": ANNOUNCE_INTERVAL,
                    "complete": swarm.seeders,
                    "incomplete": swarm.leechers,
                    "peers": swarm.sample_compact(50)
                })

        http_resp = (
            f"HTTP/1.1 200 OK\r\n"
            f"Content-Type: text/plain\r\n"
            f"Content-Length: {len(payload)}\r\n"
            f"Connection: close\r\n\r\n"
        ).encode("ascii") + payload
        writer.write(http_resp)
        await writer.drain()
    except Exception:
        pass
    finally:
        writer.close()

import dgram from 'node:dgram';
import http from 'node:http';
import crypto from 'node:crypto';

const BEP15_MAGIC = 0x41727101980n;
const INTERVAL_SEC = 1800;
const HMAC_SECRET = crypto.randomBytes(32);

// Map<infoHashHex, { peers: Map<peerKeyHex, { buf: Buffer, seeder: boolean, ts: number }>, completed: number }>
const swarms = new Map();

function bencode(data) {
  if (typeof data === 'number' || typeof data === 'bigint') {
    return Buffer.from(`i${data}e`, 'ascii');
  }
  if (Buffer.isBuffer(data)) {
    return Buffer.concat([Buffer.from(`${data.length}:`, 'ascii'), data]);
  }
  if (typeof data === 'string') {
    const b = Buffer.from(data, 'utf8');
    return Buffer.concat([Buffer.from(`${b.length}:`, 'ascii'), b]);
  }
  if (Array.isArray(data)) {
    return Buffer.concat([Buffer.from('l'), ...data.map(bencode), Buffer.from('e')]);
  }
  if (data && typeof data === 'object') {
    const keys = Object.keys(data).sort();
    const chunks = [Buffer.from('d')];
    for (const k of keys) {
      chunks.push(bencode(k), bencode(data[k]));
    }
    chunks.push(Buffer.from('e'));
    return Buffer.concat(chunks);
  }
  throw new TypeError('Invalid Bencode input');
}

function makeConnectionId(ip, bucket = Math.floor(Date.now() / 60000)) {
  const mac = crypto.createHmac('sha256', HMAC_SECRET)
    .update(`${ip}:${bucket}`)
    .digest();
  return mac.readBigUInt64BE(0);
}

function verifyConnectionId(ip, connId) {
  const b = Math.floor(Date.now() / 60000);
  return connId === makeConnectionId(ip, b) || connId === makeConnectionId(ip, b - 1);
}

function packIpv4Port(ipStr, port) {
  const octets = ipStr.replace(/^::ffff:/, '').split('.').map(Number);
  if (octets.length !== 4 || octets.some(n => Number.isNaN(n) || n < 0 || n > 255)) {
    return null;
  }
  const buf = Buffer.allocUnsafe(6);
  buf[0] = octets[0];
  buf[1] = octets[1];
  buf[2] = octets[2];
  buf[3] = octets[3];
  buf.writeUInt16BE(port & 0xffff, 4);
  return buf;
}

function upsertSwarmPeer(infoHashHex, compactBuf, leftBigInt, eventCode) {
  let swarm = swarms.get(infoHashHex);
  if (!swarm) {
    swarm = { peers: new Map(), completed: 0 };
    swarms.set(infoHashHex, swarm);
  }
  const key = compactBuf.toString('hex');
  if (eventCode === 3) {
    swarm.peers.delete(key);
  } else {
    if (eventCode === 1) swarm.completed += 1;
    swarm.peers.set(key, {
      buf: compactBuf,
      seeder: leftBigInt === 0n,
      ts: Date.now()
    });
  }

  let seeders = 0;
  let leechers = 0;
  const cutoff = Date.now() - 2400_000;
  const activeBufs = [];

  for (const [k, v] of swarm.peers.entries()) {
    if (v.ts < cutoff) {
      swarm.peers.delete(k);
      continue;
    }
    if (v.seeder) seeders++;
    else leechers++;
    if (activeBufs.length < 50) activeBufs.push(v.buf);
  }

  return { seeders, leechers, completed: swarm.completed, peersBlob: Buffer.concat(activeBufs) };
}

// 1. UDP BEP-15 Server
const udpServer = dgram.createSocket('udp4');

udpServer.on('message', (msg, rinfo) => {
  if (msg.length < 16) return;
  const connId = msg.readBigUInt64BE(0);
  const action = msg.readUInt32BE(8);
  const txId = msg.readUInt32BE(12);

  // Action 0: Connect
  if (action === 0 && connId === BEP15_MAGIC) {
    const resp = Buffer.allocUnsafe(16);
    resp.writeUInt32BE(0, 0);
    resp.writeUInt32BE(txId, 4);
    resp.writeBigUInt64BE(makeConnectionId(rinfo.address), 8);
    udpServer.send(resp, rinfo.port, rinfo.address);
    return;
  }

  if (!verifyConnectionId(rinfo.address, connId)) return;

  // Action 1: Announce
  if (action === 1 && msg.length >= 98) {
    const infoHashHex = msg.subarray(16, 36).toString('hex');
    const left = msg.readBigInt64BE(64);
    const event = msg.readUInt32BE(80);
    const port = msg.readUInt16BE(96);

    const compact = packIpv4Port(rinfo.address, port);
    if (!compact) return;

    const stats = upsertSwarmPeer(infoHashHex, compact, left, event);
    const header = Buffer.allocUnsafe(20);
    header.writeUInt32BE(1, 0);
    header.writeUInt32BE(txId, 4);
    header.writeUInt32BE(INTERVAL_SEC, 8);
    header.writeUInt32BE(stats.leechers, 12);
    header.writeUInt32BE(stats.seeders, 16);

    udpServer.send(Buffer.concat([header, stats.peersBlob]), rinfo.port, rinfo.address);
  }
});

// 2. HTTP Raw-Byte Query Parser & Announce Endpoint
function decodeRawPercentBytes(rawStr) {
  const bytes = [];
  for (let i = 0; i < rawStr.length; i++) {
    if (rawStr[i] === '%' && i + 2 < rawStr.length) {
      bytes.push(parseInt(rawStr.slice(i + 1, i + 3), 16));
      i += 2;
    } else {
      bytes.push(rawStr.charCodeAt(i) & 0xff);
    }
  }
  return Buffer.from(bytes);
}

const httpServer = http.createServer((req, res) => {
  const [path, query = ''] = (req.url || '').split('?');
  if (path !== '/announce') {
    res.writeHead(404);
    return res.end(bencode({ 'failure reason': 'Not found' }));
  }

  const params = {};
  for (const pair of query.split('&')) {
    const [k, v = ''] = pair.split('=');
    params[k] = v;
  }

  const ihBuf = decodeRawPercentBytes(params.info_hash || '');
  if (ihBuf.length !== 20) {
    res.writeHead(400);
    return res.end(bencode({ 'failure reason': 'Invalid 20-byte info_hash' }));
  }

  const port = parseInt(params.port || '6881', 10);
  const left = BigInt(params.left || '1');
  const evMap = { started: 2, completed: 1, stopped: 3 };
  const eventCode = evMap[params.event] || 0;

  const compact = packIpv4Port(req.socket.remoteAddress || '127.0.0.1', port);
  if (!compact) {
    res.writeHead(400);
    return res.end(bencode({ 'failure reason': 'IPv4 required' }));
  }

  const stats = upsertSwarmPeer(ihBuf.toString('hex'), compact, left, eventCode);
  const body = bencode({
    interval: INTERVAL_SEC,
    complete: stats.seeders,
    incomplete: stats.leechers,
    peers: stats.peersBlob
  });

  res.writeHead(200, { 'Content-Type': 'text/plain', 'Content-Length': body.length });
  res.end(body);
});

MOD 05 Code, Memory & Data Security: Hardening Trackers Against Adversarial Swarms
▶

Public and private trackers are prime targets for reflective amplification attacks, Bencode parser exploits, Sybil swarm pollution, and forensic memory extraction. Hardening requires strict defensive engineering at every layer.

Critical Vulnerability: UDP Reflective Amplification (CVE-Class) If a UDP tracker responds to an announce request (98 bytes) with 100 peers (620 bytes) without first verifying a cryptographic connection_id issued to the source IP during a 16-byte connect handshake, an attacker can spoof a victim's IP address and achieve a 6.3x bandwidth amplification factor. Never skip or weaken the HMAC connection_id validation.

5.1 Bencode Parser Fuzzing & Zip-Bomb Defenses

  • Nesting Depth Cap: Malicious payloads like llllllllllllllll...eeee (100,000 nested lists) trigger StackOverflowException in recursive descent parsers. Enforce MAX_DEPTH = 16 (standard .torrent files never exceed depth 4).
  • Pre-Allocation Length Smashing: A payload starting with 2147483647:a will trick naive parsers into allocating a 2 GB byte array before verifying that 2 GB of bytes actually exist in the socket buffer. Always assert declaredLength <= remainingBufferBytes before allocating.
  • Hash-DoS Collision Resistance: In Python, C#, and Node.js, standard dictionary keys are randomized per process via SipHash/Marvin, but custom InfoHash.GetHashCode() implementations using simple XOR are vulnerable to pre-computed multi-collision tables that degrade O(1) hash lookups into O(N^2) CPU lockups. Key your in-memory hash tables with a per-boot random 64-bit seed.

5.2 Cryptographic Private Tracker Passkeys (Zero-DB-Lookup HMAC)

Legacy private trackers store a random 32-character passkey per user in SQL and execute a SELECT on every announce. Under heavy swarm load, this saturates database IOPS. Instead, construct a structured, self-verifying token:

Passkey = Base64Url( UserID_uint32 || KeyEpoch_uint16 || Truncated_HMAC_SHA256(ServerMasterKey, UserID || KeyEpoch || InfoHashSalt) )

The tracker validates the passkey on the edge thread in ~150 nanoseconds using constant-time comparison (CryptographicOperations.FixedTimeEquals in C#, hmac.compare_digest in Python) without touching disk or SQL.

5.3 Zero-Disk Forensics & Volatile RAM Execution

  • Swap & Core Dump Lockdown: On Linux tracker nodes, invoke mlockall(MCL_CURRENT | MCL_FUTURE) via P/Invoke or ctypes and set prctl(PR_SET_DUMPABLE, 0) so kernel crash dumps or swap partitions never write peer IP tables to persistent NVMe blocks.
  • IP Anonymization via Keyed BLAKE3 / SipHash: If a public tracker only needs to enforce per-IP rate limits without storing raw peer IPs in metrics logs, hash the client IP with a rotating 15-minute salt in volatile memory.

8.1 Information-Theoretic PIR (Private Information Retrieval) Blind Trackers

Academic Basis: Chor, Goldreich, Kushilevitz, Sudan (FOCS / JACM) & Devetak / Goldberg Multi-Server PIR; extended by DPF (Distributed Point Functions — Boyle, Gilboa, Ishai).

The Problem: When a client queries a tracker for info_hash $i \in \{0, \dots, M-1\}$, the tracker operator learns that the client is interested in torrent $i$.
The Theoretical Protocol: Suppose the swarm database is replicated across $k \ge 2$ non-colluding tracker mirrors, modeled as an $M$-row matrix $D$ where row $D[i]$ is the fixed-size compact peer list (e.g., 300 bytes = 50 peers) for torrent $i$. To fetch row $t$ without any tracker learning $t$:

  1. The client generates $k-1$ cryptographically random bitvectors $v_1, \dots, v_{k-1} \in \{0,1\}^M$.
  2. The client computes $v_k = v_1 \oplus v_2 \oplus \dots \oplus v_{k-1} \oplus e_t$, where $e_t$ is the unit basis vector with a 1 solely at index $t$ and 0 everywhere else.
  3. The client sends $v_j$ to Tracker $j$. Each $v_j$ is marginally uniform random—no single tracker (or up to $k-1$ colluding trackers) gains a single bit of Shannon information about $t$.
  4. Tracker $j$ computes the XOR-inner-product $R_j = \bigoplus_{m=0}^{M-1} (v_j[m] \cdot D[m])$ and returns the 300-byte result $R_j$.
  5. The client XORs the responses: $\bigoplus_{j=1}^k R_j = D[t]$.
Figure 8.1: Information-Theoretic 2-Server XOR-PIR Swarm Discovery (Zero Tracker Knowledge of Queried Torrent)
Python // pir_blind_tracker_poc.py (Working Information-Theoretic PIR Engine) 
import os
import socket
import struct
from typing import List

ROW_BYTE_SIZE = 30  # 5 compact IPv4:Port peers (6 bytes each) per swarm slot


def xor_bytes(a: bytes, b: bytes) -> bytes:
    return (int.from_bytes(a, "big") ^ int.from_bytes(b, "big")).to_bytes(len(a), "big")


class BlindPirTrackerMirror:
    """
    Holds an identical replica of M swarm peer slots.
    Computes PIR parity responses without ever learning which slot the client requested.
    """
    def __init__(self, database_rows: List[bytes]) -> None:
        assert all(len(r) == ROW_BYTE_SIZE for r in database_rows)
        self.db = database_rows

    def answer_pir_query(self, bitvector: int) -> bytes:
        acc = bytes(ROW_BYTE_SIZE)
        for idx, row in enumerate(self.db):
            if (bitvector >> idx) & 1:
                acc = xor_bytes(acc, row)
        return acc


def pir_client_fetch_swarm(
    target_index: int,
    total_swarms: int,
    mirror_a: BlindPirTrackerMirror,
    mirror_b: BlindPirTrackerMirror
) -> bytes:
    # 1. Generate uniform random M-bit query for Mirror A
    v1 = int.from_bytes(os.urandom((total_swarms + 7) // 8), "big") & ((1 << total_swarms) - 1)
    # 2. Flip solely the target bit for Mirror B: v2 = v1 ^ (1 << target_index)
    v2 = v1 ^ (1 << target_index)

    # 3. Query both mirrors (neither learns anything about target_index)
    r1 = mirror_a.answer_pir_query(v1)
    r2 = mirror_b.answer_pir_query(v2)

    # 4. Reconstruct exact compact peer list via R1 ^ R2
    return xor_bytes(r1, r2)

8.2 DC-Nets (Dining Cryptographers) & Dissent Anonymous Announce Buses

Academic Basis: David Chaum (The Dining Cryptographers Problem: Unconditional Sender and Recipient Untraceability, J. Cryptology 1988); Wolinsky et al. (Dissent: Accountable Anonymous Group Messaging, OSDI).

The Theoretical Protocol: In small, high-trust darknet swarms (e.g., 10–64 researchers or whistleblowers, similar to WASTE topology), routing topology itself can be eliminated. Every pair of nodes $(i, j)$ establishes a shared symmetric PRNG stream $S_{i,j}$ via Diffie-Hellman. In each synchronous epoch, every node broadcasts an $L$-byte ciphertext vector equal to the XOR of all its pairwise secrets (inverting sign/orientation for $i < j$ vs $i > j$). If node $k$ wishes to publish a new .torrent magnet or tracker announce, it XORs its payload $M$ into its broadcast. When all broadcasts are XORed together by every participant, all pairwise secrets $S_{i,j} \oplus S_{i,j} = 0$ cancel out completely, revealing $M$ with information-theoretic sender anonymity—even if 62 of the 64 nodes are NSA-controlled colluders.

8.3 Zero-Knowledge Proof of Bandwidth / Ratio (zk-SNARK Trackerless Private Swarms)

Academic Basis: Decentralized Fair Exchange & Zero-Knowledge Micropayment Channels (Boneh / Bünz / Fisch; Filecoin Proof-of-Spacetime / Proof-of-Data-Possession).

The Problem: Private trackers require central databases tracking every user's upload/download ratio, creating a massive honeypot linking user accounts, passkeys, IP history, and snatched torrents.
The Theoretical Protocol: Replace the tracker's user ratio table with blind Bandwidth Receipts and a Groth16 / Plonky2 zk-SNARK circuit:

  • When Seeder $S$ sends piece $P_k$ to Leecher $L$, $L$ returns a blind Schnorr/BLS signature $\sigma_k$ over the tuple $(\text{Commitment}(S), \text{Epoch}, \text{PieceHash}_k)$.
  • To join a new swarm or request peers from a blind tracker, $S$ generates a zero-knowledge proof $\pi$ proving: "I know $N$ distinct valid bandwidth receipts $\sigma_1, \dots, \sigma_N$ corresponding to my blinded Pedersen commitment $C = g^{\text{id}} h^r$, and their nullifiers have not been spent"—without revealing which torrents were seeded, when they were seeded, or the user's identity.

8.4 Random Linear Network Coding (RLNC) Over Plausibly Deniable Mix Swarms

Academic Basis: Gkantsidis & Rodriguez (MSR Avalanche); Ahlswede, Cai, Li, Yeung (Network Information Flow, IEEE Trans. Info Theory); OFFSystem / Owner-Free File System.

The Theoretical Protocol: Standard BitTorrent suffers from the "last-piece coupon collector problem" and allows adversaries to identify exactly which file a node possesses by inspecting piece hashes. Under Galois Field $GF(2^8)$ Random Linear Network Coding:

  1. A file is split into $K$ source vectors $B_1, \dots, B_K$ over $GF(2^8)$.
  2. No peer ever transmits or stores a raw piece $B_i$. Instead, whenever a node forwards data or caches blocks on disk, it draws $K$ random coefficients $c_1, \dots, c_K \in GF(2^8)$ and transmits the linear combination $Y = \sum_{i=1}^K c_i B_i$ alongside the $K$-byte coefficient header $\vec{c}$.
  3. Intermediate mix nodes can re-encode two coded blocks $Y^{(1)}, Y^{(2)}$ into a new coded block $Y^{(3)} = \alpha Y^{(1)} + \beta Y^{(2)}$ without ever decoding the file.
  4. Once a downloader collects any $K$ linearly independent coded blocks, it inverts the $K \times K$ coefficient matrix via Gaussian elimination over $GF(2^8)$ to reconstruct the original file.
C# .NET 8 // Gf256NetworkCodingSwarm.cs (GF(2^8) Polynomial 0x11B Linear Block Encoder) 
using System;
using System.Security.Cryptography;

namespace SwarmNexus.Theoretical
{
    /// <summary>
    /// Galois Field GF(2^8) Random Linear Network Coding (RLNC) Engine
    /// Irreducible AES polynomial: x^8 + x^4 + x^3 + x + 1 (0x11B)
    /// Enables intermediate mix-peers to re-combine encrypted swarm pieces without decoding.
    /// </summary>
    public static class Gf256RlncEngine
    {
        private static readonly byte[] ExpTable = new byte[512];
        private static readonly byte[] LogTable = new byte[256];

        static Gf256RlncEngine()
        {
            int x = 1;
            for (int i = 0; i < 255; i++)
            {
                ExpTable[i] = (byte)x;
                ExpTable[i + 255] = (byte)x;
                LogTable[x] = (byte)i;
                x = (x << 1) ^ ((x & 0x80) != 0 ? 0x11D : 0); // Generator 2 with 0x11D primitive
            }
        }

        public static byte Mul(byte a, byte b) =>
            (a == 0 || b == 0) ? (byte)0 : ExpTable[LogTable[a] + LogTable[b]];

        /// <summary>
        /// Produces a fresh coded block Y = Sum(coeff[i] * SourceBlock[i]) in GF(2^8).
        /// Every peer in the swarm transmits unique algebraic combinations—eliminating piece rarity.
        /// </summary>
        public static (byte[] Coefficients, byte[] CodedPayload) EncodeLinearCombination(byte[][] sourcePieces)
        {
            int k = sourcePieces.Length;
            int pieceLen = sourcePieces[0].Length;
            byte[] coeffs = RandomNumberGenerator.GetBytes(k);
            byte[] coded = new byte[pieceLen];

            for (int i = 0; i < k; i++)
            {
                byte c = coeffs[i];
                if (c == 0) continue;
                byte[] src = sourcePieces[i];
                for (int b = 0; b < pieceLen; b++)
                {
                    coded[b] ^= Mul(c, src[b]); // Addition in GF(2^8) is bitwise XOR
                }
            }
            return (coeffs, coded);
        }
    }
}

8.5 Oblivious RAM (Path-ORAM) Distributed Hash Tables

Academic Basis: Stefanov et al. (Path ORAM: An Extremely Simple Oblivious RAM Protocol, CCS / JACM); Keller & Scholl Oblivious Data Structures.

The Theoretical Protocol: Even if a tracker uses encrypted Intel SGX / AMD SEV-SNP confidential computing enclaves, an adversary with root hypervisor access can observe the enclave's RAM page-fault and cache-line access patterns to deduce which swarms are popular or which two peers are accessing the same info_hash bucket. Wrapping the tracker's swarm table in a binary tree Path-ORAM assigns every info_hash to a uniformly random leaf path $L \in \{0, \dots, 2^H - 1\}$. On every announce, the enclave reads and re-encrypts the entire root-to-leaf path ($O(\log N)$ buckets), remaps the info_hash to a brand-new random leaf $L'$, and flushes its local Stash back into the tree—making any two swarm accesses computationally indistinguishable to a hardware bus snooper.
